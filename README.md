# 项目简介

## 核心功能
- 登录注册
- 管理员与用户角色切换
- 菜品信息管理
- 菜品分类管理
- 菜品资讯管理
- 个人中心
- 菜品图片和简介信息添加
- 个人信息查看与密码修改
- 用户管理
- 餐桌管理
- 菜品订单管理
- 菜品评价管理
- 系统管理

## 适用场景
- 餐厅、快餐店等餐饮服务行业
- 提供便捷的点餐服务
- 管理菜品信息与订单
- 实现用户个人信息管理

## 技术特点
- 采用B/S架构模式，易于部署和维护
- 使用Java JDK1.8作为开发环境
- 开发工具为IDEA
- 数据库采用mysql8.0，可视化工具为navicat
- 服务器使用springboot自带tomcat
- 主要技术包括Springboot、mybatis、mysql、html、vue、elementUI等
